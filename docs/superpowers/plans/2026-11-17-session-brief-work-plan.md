## 1. 截图里的分析是怎么做出来的

每篇文章都是同一个固定模板，可以拆成五个部件：

| 部件 | 截图原文举例 | 用到的数据 | 判断方式 |
| --- | --- | --- | --- |
| 隔夜外盘 | "晚间A50指数跌-0.28%" | 富时中国 A50 期货夜盘涨跌幅 | 只报数字 |
| 盘面统计 | "两市超4100只个股绿盘、量能1.46万亿较上日缩量268亿"；"光刻机、芯片半导体和工业气体板块领涨" | 两市成交额、涨跌家数、板块涨跌排名 | 只报数字 |
| 关键位与形态 | "3690点得而复失"；"三重底诱空（3574-3580-36X0，X=012345）"；"回踩平台下沿后险守3600点"；"第三次回踩" | 日线高低点、收盘价 | 人工画线：前低 3574、3580 当前两只脚，推测第三只脚落在 3600~3650；3690 为收复与否的分水岭 |
| 时间窗口 | "11月5日正负1天、11月17日正负1天"；"第一个时间窗口出现惊天大阳线" | 无公开方法 | 事先给出变盘日，事后对照 |
| 结论与操作 | "构筑三重底概率大些""可保持信心等待回补仓位或加仓时机"；"预计今日沪指分时节奏为震荡" | — | 主观判断，附组合仓位与收益率 |

三类文章的分工：

- **盘前策略（约 07:00）**：A50 夜盘 → 回顾昨日 → 重申关键位与形态假设 → 时间窗口 → 预计今日分时节奏。
- **午评（约 11:30~13:00）**：上午盘面统计（高开低开、领涨板块、绿盘家数、半日成交额较上日同时段增减）→ 上午最低点与关键位的关系（"早盘 3593 是 3574 到 3580 的第三次回踩"）→ 拖累板块 → 组合持仓。
- **收评（约 15:30）**：全天盘面统计 → K 线描述（"三大指数四连阴、同创年内新低"）→ 关键位状态 → 下一步观察点 → 组合持仓。

### 1.1 用真实行情核对（2026-11-17 收盘后）

数据：新浪日线（本技能 `SINA_LIVE_DAILY`）、腾讯实时快照与 5 日分钟线、东方财富涨跌家数。

**盘面统计可以逐位复现。** 截图里的"两市成交额"等于上证指数成交额加深证成指成交额，半日数取 11:30 那一分钟的累计额：

| --- | --- |
| 11-12 收评："量能 1.93 万亿较上日放量 2558 亿" | 19321 亿，较 11-11 的 16763 亿多 2558 亿 |
| 11-16 午评："量能 9006 亿较上日缩量 788 亿" | 上午 9006 亿，较 11-13 上午 9794 亿少 788 亿 |

| 11-17 收评："量能 1.46 万亿较上日缩量 268 亿" | 14577 亿，较 11-16 少 268 亿 |

| 11-17 收评："四连阴、年内新低" | 11-12、11-13、11-16、11-17 四天收盘均低于开盘；11-17 最低 3565.59 低于此前年内最低 3574.27（10-23），收盘 3584.58 低于此前年内最低收盘 3599.02（10-30） |

**形态判断和时间窗口经不起核对：**

- **目标区间随价格下移。** 11-12、11-13 写第三只脚在 3600~3650（X=0~5），11-16 改成"X=012?"，11-17 改成"濒临平台下沿岌岌可危"。实际 11-16 最低 3586.57 已低于 3600，11-17 最低 3565.59 已跌破第一只脚 3574.27。整个过程没有事先写明"跌破多少即三重底失效"。
- **两头都说到。** "三重底构筑成功还是形成平台下跌中继"同时覆盖了两种结果，事后怎么走都不算错。
- **"概率在加大""概率大些"没有任何数字或统计依据**，属于主观措辞。
- **时间窗口没有公开计算方法。** 11-05 窗口内 11-04 确有 +2.16% 的大阳线（3608.10 → 3686.17），但一次命中不能说明方法有效；11-17 窗口前两天为 11-16 −0.87%、11-17 −0.50%，11-18 尚未发生。
- **"预计今日分时节奏为震荡/回落反弹"** 措辞宽泛，几乎任何走势都能对上。
- 作者自己披露的组合收益：短线组合今年在 −2% ~ +0.9% 之间（截图日期不同，数值不同），中线组合 +6.5% ~ +8%。

结论：**盘面统计**是可复现的事实；**几重底、平台这类结构判断**可以用确定性规则做，而且应该由数据决定，不能预设"三重底"再找脚；**时间窗口、概率措辞与分时节奏预测**无法复现，也违反本仓库的铁律 5。

## 2. 本技能现在能做什么、缺什么

| 部件 | 现在 | 缺口 |
| --- | --- | --- |
| 双底 / 双顶 | `patterns.detect_geometric_patterns` 只取**最近两个**已确认低点（高点）比较，N 写死为 2 | 识别不出三重底、多次测试的平台；两个低点之外的触点被忽略 |
| 轨道形态 | `structure._classify` 用最近 4 个同类拐点拟合上下轨，分为楔形、三角形、通道、箱体、喇叭形 | 只有一个级别（ZigZag 阈值 2×ATR%，3%~8%）；没有"同价区被测试几次"的概念 |
| 拐点 | 因果 ZigZag，单一阈值 | 没有次级别拐点，近端的小级别测试（几天内的回踩）看不到 |
| 状态 | 双底只有"结构 / 突破"两态 | 没有"测试进行中 / 守住 / 破位 / 破位后收回"；没有日与日之间的状态变化 |
| 收盘后的技术部分 | 15:00 后运行即用当天已收盘K线 | 无 |
| 午间 | 未收盘K线被拆出，只用于"盘中触及 / 刺破（未收盘，不作确认）"标注 | 无盘面统计 |
| 盘面统计、板块、A50 | 没有 | 需要新增取数 |

## 3. 动态结构识别（新增，简报的前置）

完整规则、常量、输出契约、测试与验收见规格 `docs/superpowers/specs/2026-11-17-tested-zones-design.md`。要点：

1. **两个级别**：主级别沿用结构层现有 ZigZag 阈值；次级别为 1×ATR% 按 0.5% 取整，夹在 1.5%~4%。
2. **同价区聚类决定 N**：触点间价差不超过 0.65 ATR、两次触点之间没有收盘打穿价区 0.5 ATR，就并入同一价区。N=2 为双底 / 双顶，N=3 为三重底 / 三重顶，N≥4 为"N 次测试的支撑区 / 压力区"。
3. **失效价只由已确认触点决定**（已确认最低点 − 0.5 ATR），未确认的新低不会把它往下带；未确认触点给出确认价（低点 ×（1 + 级别阈值））。
4. **状态**：测试进行中、守住、越过颈线、破位、假破位（3 根内收回）；破位后超过 3 根才收回的价区视为失效，不再输出。
5. **另识别头肩底 / 头肩顶与平台**（一个支撑价区与一个压力价区时间重叠、间距不少于 1.2 ATR）。
6. **与上一根已收盘K线比较，列出变化**（新增触点、触点确认、状态改变、价区消失等），报告与简报按变化组织文字。
7. 全部为描述性实验字段 `structure.tested_zones`，不参与评分与决策。

参考原型在真实行情上的结果（规格第 11.2 节的固定样例）：

- **上证指数 2026-11-17**：主、次两个级别都是三重底（10-23 3574.27、11-03 3580.38、11-17 3565.59 未确认），测试进行中；颈线 3708.20，失效价 3548.04，确认价主级别 3672.56、次级别 3619.07。压力侧主级别为双顶、次级别为三重顶（3708.20、3701.59、3699.58，高点逐次降低）。两级都合成 3574.27 ~ 3708.20 的平台。
- **逐日变化**：11-13 还是双底（守住）；11-16 的低点 3586.57 并入，成为三重底（第 3 次测试进行中）；11-17 未确认触点由 3586.57 更新为 3565.59，失效价不变（只因 ATR 变化差 0.06）。同一过程中次级别 11-06 起的小双底因未确认触点被取代而消失。
- **贵州茅台 2026-10-15**：07-27 / 08-24 的双底在 9 月被收盘跌破、3 根以后才收回，判为失效，不再输出（上一版原型误报为"守住"）。
- **比亚迪 2026-10-15**：主级别是 81.51 ~ 87.20 的平台；次级别 5~8 月有两个 4 次测试的压力区，已跌破颈线，且离现价远，不入选（上一版原型误合并为一个 7 次测试的压力区）。
- **头肩**：上证指数 2025-03-24 / 04-07 / 05-27 的头肩底（次级别）与 2026-03-03 / 05-14 / 06-23 的头肩顶（主级别）都能识别；一个跨越 4 月暴跌、颈线陡斜的"头肩顶"被颈线斜率约束排除。

全部 11 份录制行情、每 5 根一个截面回放：两级都出现了 N=2 到 N≥5 的价区与全部五种状态，头肩与平台都有出现，没有某一种写死的结构。

## 4. 本技能能不能这样写简报

| 部件 | 能否做 | 做法 |
| --- | --- | --- |
| 收盘后的技术部分 | 能 | 第 3 节的动态结构识别 + 现有关键位、轨道、条件推演 |
| 午间的技术部分 | 能，受铁律 0 约束 | 结构全部来自截至上一交易日的已收盘K线；上午最低（最高）价若落在某价区内，写"第 N 次测试进行中（盘中，未确认）"，不重算拐点 |
| 盘面统计（两市成交额、较上日 / 同时段增减、涨跌家数） | 能 | 腾讯实时快照、腾讯 5 日分钟线、东方财富涨跌家数（11-17 已确认三个接口可用） |
| 板块领涨领跌 | 能（只描述排名） | 东方财富板块排名接口，待验证；不做"某板块拖累大盘"的因果归因 |
| A50 夜盘 | 能（取不到写 `null`） | 新浪 `hf_CHA50CFD`，字段含义待确认 |
| 连阴连阳、N 日新低新高、年内新低 | 能 | 已收盘K线上的纯计算 |
| 时间窗口（变盘日 ±1 天） | **不进产品** | 无公开方法 |
| "X 概率在加大" | **不做** | 改写成条件句："收盘站上 A → 目标 B；收盘跌破 C → 结构失效" |
| 预计今日分时节奏 | **不做** | 属于方向预测，且无法检验 |
| 组合仓位与收益率 | 不做 | 可用已有的回测统计说明规则本身的历史表现 |

本技能可以比截图做得更好的两点：

- **结构由数据决定**，几重底、平台上下沿、确认价和失效价都由规则算出，不会出现事后挪动目标区间。
- **每份简报都写下条件，下一份自动对账**（昨天的确认价、失效价今天有没有被触及）。

## 5. 简报设计要点

1. **新 CLI，不改主流程。** 新增 `scripts/session_brief.py --session {premarket,midday,close}`，只支持 A 股大盘（上证指数为主，附深证成指、创业板指的涨跌幅与成交额），不接受个股或港美股代码（传入时以 `[INVALID_ARGUMENT]` 退出）。技术部分调用现有流水线得到 `result.json`，简报只读它，不重算点位（铁律 1）。
2. **新产物、独立契约。** 输出 `*_brief.json` 与 `*_brief.md`，用新的 `assets/brief.schema.json`，字段一律 `x-stability: experimental`。
3. **午间严格遵守铁律 0。** 简报写明"以下结构与关键位由截至 YYYY-MM-DD 的已收盘K线计算，盘中价只作对照，不作确认"；盘中最高最低取实时快照字段，不用分钟收盘价。
4. **取数走 `data_gateway._http_get`。** 每个新接口有录制 fixture 与失败测试；取不到写 `null` 并在 `quality.notes` 注明来源，不估算、不用其他口径补数（铁律 0）。
5. **口径写死并披露。** "两市成交额 = 上证指数成交额 + 深证成指成交额"；"同时段"按交易所分钟（午间取 11:30）；涨跌家数注明是否含北交所。口径写进 `references/cn-market.md`（或新建 `references/session-data.md`）。
6. **文字由状态变化驱动，只有三种句式。** 事实（数字来自 JSON）、条件（触发 → 目标 → 失效，确认价与失效价来自第 3 节）、对账（昨日条件是否发生）。今天没有状态变化的结构只用一句话带过，有变化的结构展开写。`lint_response.py` 新增简报模式：价格白名单取自 `brief.json` 与 `result.json`，拦截"概率在加大""大概率""时间窗口""变盘日""预计今日分时"等措辞。
7. **版本。** 新增 CLI、产物与实验字段属于向后兼容的新增，发布时升 `6.1.0`，五处版本号同步，`CHANGELOG.md` 写在 `[Unreleased]`。

## 8. 风险

- **结构识别的参数敏感**：容差、级别阈值稍变，N 就可能变。对策：常量在规格里一次写定，不按结果调参；两个级别并列输出，让"几重"随级别变化是可见的，而不是藏起来。
- **N 被误读为可靠程度**：对策：解读指南与回复契约写明"测试次数只是描述，不代表支撑更可靠或更容易破"，`lint_response.py` 拦截"测试次数越多越……"一类说法。
- **接口变动**：东方财富、腾讯分钟线都是非公开接口，字段可能变化。对策：录制 fixture、字段校验失败即写 `null` 并注明，`doctor.py` 增加连通检查。
- **口径争议**：两市成交额、涨跌家数在不同 App 上口径不一。对策：口径写死并在简报里注明来源。
- **午间被误读为预测**：对策：固定开头说明 + `lint_response.py` 拦截。
- **交易日历**：`CALENDAR_COVERAGE_END` 的 A 股覆盖到 2026-12-31，2027 年放假安排公布后须补录，否则定时任务会在节假日误运行。
