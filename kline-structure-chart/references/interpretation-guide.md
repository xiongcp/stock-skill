# 解读指南：形态、浪型、市场状态、风控、区间与回测

用户追问"这个形态说明什么""为什么风控否决""区间怎么看"时阅读。本文件只给解读要点和常见误读，所有点位一律取自本次运行的 `*_result.json` / `*_report.md`。字段含义见 `references/output-fields.md`，计算公式见 `references/math-patterns.md`。

## 1. 总原则

1. **先大盘、后个股**：先说基准的状态与状态分，再说个股。基准状态分低于 35 时，个股结构再好也只能说"观察"。
2. **结构描述 ≠ 方向预测**：形态、浪型和市场状态都只描述"现在长什么样"。15 个交易日的涨跌方向本身接近随机，不得用形态推出"必涨""必跌"。
3. **条件化表述**：一律写成"如果日线收盘站上 A → 目标 B；收盘跌回 C 下方 → 失效"，不写"会涨到 B"。
4. **收盘为准**：触发与失效都以日线收盘判定，盘中刺破不算；报告带"待收盘确认"时必须保留。
5. **不加料**：报告没有的价位、指标、新闻、资金面一律不补；用户提供的消息面信息要标注"未复核"。

## 2. 轨道形态（`wedge_structure`）

| 形态 | 怎么读 | 常见误读 |
| --- | --- | --- |
| 上升通道 / 下降通道 | 上下轨同向；价格在通道内运行，接近上轨看压力、接近下轨看支撑 | 把通道直接外推成目标价；通道只描述过去 120 日的结构 |
| 对称三角形 | 上轨向下、下轨向上，波动收敛；关注收盘向哪一侧越出 | 默认"向上突破"；收敛形态本身没有方向 |
| 上升三角形 / 下降三角形 | 一侧水平、一侧倾斜 | 教科书说"上升三角形看涨"，但本技能只按 `status_text` 描述当前状态 |
| 上升楔形 / 下降楔形 | 两轨同向且收敛 | "下降楔形必然上涨"；以脚本的 `status`（`above`/`inside`/`below`）为准 |

- `status = above` / `below` 表示收盘已在上轨之上 / 下轨之下，`status_text` 写明从哪天起、已连续几日。刚越出 1~2 日的突破容易回落，报告的假突破规则（`false_breakout_rule`）就是用来判定这种情况的。
- `apex_bars_ahead` 很小或 `expired = true`：收敛形态接近顶点或已过期，结构参考价值下降。
- 注意：5.1.0 版本的轨道拟合偏向判出收敛类形态（对称三角形占比偏高），解读时不要把"对称三角形"当成特殊信号。

## 3. ABC 浪型（`abc_scenario`）

- 只引用 `label`、`phase`、`b_retrace`、`c_progress.c_over_a` 和 `levels` 的原文，不自行数浪、不扩展成五浪。
- A 浪起点是结构窗口内的最高点（下跌 ABC）或最低点（上涨 ABC），**不是**主图窗口最低点；窗口高低点另见 `legacy_summary.window_high` / `window_low`。
- `phase` 为"C 浪进行中"时，C 浪终点未知，`levels` 里的 1.0×A、1.618×A 只是测算位，不是目标价承诺。
- 5.1.0 版本每次只给一个计数，没有备选数法；用户追问"有没有别的数法"时如实说明。

## 4. 支撑压力阶梯（`key_levels`）

- 每个价位都带来源（前高、前低、均线、斐波那契、轨道、ABC 测算位），转述时带上来源，按"由近到远"排列。
- 多个来源重合的价位更值得关注，但这只是描述，不代表"一定守住"。
- 大级别背景（`series_export.background`，近 250 日）只描述位置，不作为触发位、失效位或目标位。

## 5. 市场状态（`market_regime` / `market_benchmark.regime`）

| 状态 | 判定要点 | 解读 | 常见误读 |
| --- | --- | --- | --- |
| `TRENDING_BULL` 多头趋势 | ADX ≥ 23，收盘在 EMA60 上方且 +DI ≥ −DI | 顺势策略占优 | 当成"会继续涨"的预测 |
| `TRENDING_BEAR` 空头趋势承压 | ADX ≥ 23，收盘在 EMA60 下方且 −DI > +DI | 做多需要更强证据 | 当成"会继续跌"的预测 |
| `SQUEEZE_CONSOLIDATION` 收敛蓄势 | 布林带宽分位 ≤ 22 且 ADX < 24 | 波动收窄，等待方向选择 | 说成"即将暴涨" |
| `MEAN_REVERTING_RANGE` 区间震荡 | 不满足上面条件 | 区间两端更有参考价值 | — |
| `HIGH_VOLATILITY_CHAOS` 高波失序 | VIX ≥ 28，或 20/60 日波动比 ≥ 1.55，或 ATR20 ≥ 4.5%（优先于其他状态判定） | 波动放大，止损距离变宽、同样风险下股数变少 | 当成"恐慌底" |

- 状态分 `regime_score`（5~95）是规则加减分，不是概率；只有"低于 35 触发风控否决"这一条有硬规则含义。

## 6. 规则分与动作标签

- `rule_score`（0~100）= 四组各 25 分的规则加权。它**不是**胜率、上涨概率或置信度，也没有经过逐标的的样本外检验；用户问"81 分是不是很稳"时要明确说明这一点。
- 动作标签（确认做多 / 条件观察 / 观望 / 防守回避）由规则分、计划类型和风控否决共同决定。风控否决时一律只能说观察或防守。
- 回测里不同动作标签的后续收益没有稳定差异时，不得说"确认做多信号更可靠"。

## 7. 风控计划与否决

- 否决原因常见四类：大盘状态分 < 35；扣费后 TP1 净盈亏比 < 1.20；收盘在结构下轨下方；右侧突破缺量（RVOL < 1.15）。逐条原文转述，放在回答最前面。
- 入场区、止损、TP1/TP2、时间屏障构成一套完整计划，不得只挑其中一个价位。
- 仓位股数是按"账户净值 × 单笔风险 ÷ 止损距离"并按每手取整的机械计算，不是个性化建议；港股每手股数未取得时要提醒以券商为准。
- 做空与持仓防守：A 股融券受严格限制（见 `references/cn-market.md` 第 6 节），只谈持仓的减仓 / 离场条件；港股只能卖空指定证券且禁止裸卖空（`references/hk-market.md` 第 4 节）；美股卖空需要先借券，并受 Rule 201 约束（`references/us-market.md` 第 4 节）。报告里没有做空点位时不得自行给出。

## 8. 未来区间

- 中枢 q50 = 最新收盘价，区间只描述"未来 N 日价格大致的波动幅度"。q75 / q90 不是"乐观目标"，q25 / q10 也不是"止损位"。
- 必须同时说清：实测覆盖率、评估样本数、约等于多少个独立样本、状态（已达标 / 校准观察期）。
- 区间是逐日的边际区间，不代表整条路径的联合概率；"15 日内触及 q90"的概率不等于 10%。
- 有 `uncalibrated_overlays`（如 VIX 放大）时，区间宽度含未校准的放大项，状态不会是"已达标"。

## 9. 回测

- 先看成交笔数：少于 30 笔时胜率、夏普、盈亏比都很不稳定，必须转述 `sample_size_warning`。
- 胜率要带 Wilson 95% 区间（例如 10 笔 3 胜的区间很宽），并与"同期买入持有"对比。
- 回测是"线上同一套规则在历史上逐日重放"的结果，不学习参数；它说明这套规则过去的表现，不预测未来。
- 无前视审计 `passed = true` 只说明没有用到未来数据，不说明策略有效。

## 10. 概率与频率怎么说

- 当前版本**没有**任何情景概率字段。用户问"上涨概率多少"时回答：本技能目前不输出方向概率；可以给出的是条件推演（触发 → 目标 → 失效）、波动区间和历史回测成交统计。
- 后续版本加入"历史条件频率"字段后，写法为"历史条件频率 X%（n = …，95% 区间 a%~b%）"；加入 LLM 研判后，必须标注"主观研判，已记录待检验"。规则详见 `SKILL.md` 的"对外表述与概率规则"一节。
